# Ripple Mill Marketing

**Good work deserves to be found.** Ripple Mill is an independent marketing studio providing practical, hands-on support for owner-operated service businesses.

**Website:** [ripplemill.vercel.app](https://ripplemill.vercel.app) · **GitHub:** [jpxgs/ripplemill](https://github.com/jpxgs/ripplemill)

## What the site covers
- Local visibility and Google Business Profile support
- Review and reputation workflows
- Website and landing-page design
- Brand identity and creative support
- Lead follow-up and local advertising
- Clear service process, indicative pricing and FAQs

## Project details
- Static, zero-build website: `index.html`
- Responsive layout with accessible mobile navigation
- No framework, package manager, build step or runtime dependency
- SEO metadata, structured business data, Open Graph tags, sitemap and robots.txt
- Brand palette: forest green, warm cream and rust

## Run locally
```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Deploy
Import this repository into Vercel as a static site. No build command is required; use the repository root as the output directory (or leave the framework preset as Other).
